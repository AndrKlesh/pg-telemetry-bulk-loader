# pg-telemetry-bulk-loader
Утилита-загрузчик телеметрических данных из файлов сsv в таблицу PostgreSQL.

## Технологии
- Язык: Rust
- Сборка: Cargo

## Структура каталогов
- src/ - исходный код программы.
- .gitignore - шаблоны игнорирования Git.
- Cargo.toml - файл проекта: имя, версия, автор, зависимости.
- Cargo.lock - содержит зафиксированные версии всех зависимостей проекта.
